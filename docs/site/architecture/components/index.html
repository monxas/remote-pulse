    Components¶

    Every box in the overview diagram explained, in deployment-order.

    Agent rp¶

    • Where: Every managed host.
    • Language: Python 3.12 (+ uv) compiled to PyInstaller binaries for distribution.
    • Service: systemd unit (Linux), launchd plist (macOS), NSSM service (Windows). Configurable under packaging/.
    • Persists state at: /etc/rp/ (Linux/macOS) or %PROGRAMDATA%\rp\ (Windows).
    • host_key / host_key.pub — ed25519 keypair.
    • authorized_keys.d/managed — server-managed SSH authorized_keys.
    • allow-remote-exec, allow-remote-write, restart-whitelist, … — local-approval flags.
    • Loop: heartbeat every 30 s, full metric snapshot every 60 s, inventory diff every 5 minutes (or on-change), commands on demand.
    • Offline queue: SQLite ring buffer in /var/lib/rp/queue.db, capped at 100 MB or 24 h FIFO. Audit-log records never discarded.

    Server FastAPI¶

    • Where: LXC 280 on pmx-50 (homelab Proxmox cluster).
    • Process tree:
    • tailscaled — system daemon, joined to tailnet with tag:rp-server.
    • tailscale serve --bg --https=443 / http://127.0.0.1:8080 — reverse proxy that injects Tailscale-User-Login headers.
    • uvicorn rp_server.main:app — FastAPI app on 127.0.0.1:8080 (tailnet) and 0.0.0.0:8443 (public bootstrap-only).
    • Public endpoints: /v1/enroll, /v1/agent/reauth only. Everything else returns 401 if not via tailscale serve.
    • Modules: routers/{enroll,heartbeat,hosts,keys,metrics,admin}.py.

    Caddy HA (LXC 270/271)¶

    • Routes:
    • rp.monxas.casa → LXC 280:8443 (bootstrap public).
    • dash.rp.monxas.casa → LXC 280:8080 (web dashboard, forward_auth to PocketID).
    • Rate-limit: 10 req/min/IP on /v1/enroll.

    Storage¶

    Postgres 16 + TimescaleDB on LXC 280:

    Table Type Retention
    hosts relational infinite
    groups relational infinite
    ssh_keys relational + soft-delete (revoked_at) infinite
    enrollments relational infinite (jti audit)
    commands append-only (DB trigger blocks UPDATE/DELETE) 1 y rolling to commands_archive
    heartbeats TimescaleDB hypertable 90 d raw
    metric_samples TimescaleDB hypertable 30 d raw
    metric_samples_5min continuous aggregate 1 y
    agent_versions relational infinite

    Steady-state for a 50-host fleet: ~15 GB. LXC disk provisioned at 50 GB with alerts at 70 % / 85 % / 95 %.

    See ADR-0008 Appendix B for the full schema.

    PocketID¶

    • Where: existing homelab LXC.
    • OIDC client: remote-pulse-web registered in F5.
    • Used by: Caddy forward_auth for the web dashboard; the rp admin invite flow.

    Observability (reused stack)¶

    Service Role
    Prometheus Scrapes /metrics on the server (rp_host_up, rp_host_cpu_pct, …).
    Loki + Promtail Audit log secondary sink ({job="remote-pulse"}).
    Grafana Provisioned dashboard Remote-Pulse Fleet (Stat-sparkline panels).
    Healthchecks Server keep-alive ping.

    n8n + Telegram¶

    • Webhook: https://n8n.monxas.casa/webhook/rp-approval.
    • Bot: @Veraclawd_bot (reused; subject to F4-6 decision on whether to split a @RemotePulse_bot).
    • Flows: host-down alert, key rotated/revoked, command failed, enrollment used, clock-skew warn, approval-required with inline buttons, agent-upgrade failed.

    RustDesk client (Direct IP) F6¶

    • Where: any host with GUI.
    • Mode: Direct IP only (no rendezvous server in v1.0). LXC 281 rustdesk-server is deferred until the first case requires it.
    • Password: generated by the agent, rotatable via rp keys rotate-screen <host>.

    Sunshine + Moonlight F6¶

    • Where: Windows hosts with NVIDIA GPUs (e.g. .115 with the RTX 3080).
    • Pairing: one-time manual PIN exchange via Sunshine web admin (https://<tailscale_ip>:47990). The agent exposes the admin UI through the tailnet but cannot fully automate the handshake — limitation inherent to Sunshine.

    Promtail / fluent-bit (opt-in)¶

    • Where: in agents that pass --with-logs.
    • Role: push journald (Linux) or Windows Event Log to Loki with labels {job="remote-pulse", host=...}.
    • macOS/Windows: Promtail is fragile multi-OS; fluent-bit is the fallback there.
